Installeren op Samsung TV

De .wgt installeren met de ontwikkelaarsmodus, Tizen Studio en een eigen Samsung-certificaat.

Downloads zijn tijdelijk niet beschikbaar. De apps komen binnenkort. Tot die tijd kijk je met je account in je browser op bingr.online/web. Heb je Bingr al geïnstalleerd, dan blijft die gewoon werken.

Bingr op een Samsung TV

Bingr voor Samsung TV (Tizen) werkt op Samsung-smart-tv's van 2018 en nieuwer. Je installeert het .wgt-bestand vanaf een computer met de ontwikkelaarsmodus van de tv en een eigen Samsung-certificaat. Download het bestand met de knop Download voor Samsung TV (.wgt) op bingr.online.

1. Ontwikkelaarsmodus aanzetten op de tv

  • Zorg dat de tv en je computer op hetzelfde netwerk zitten en zoek het IP-adres van je computer op (macOS: Systeeminstellingen → Netwerk; Windows: ipconfig).
  • Open op de tv Apps en toets met de afstandsbediening 1 2 3 4 5 in (zonder cijfertoetsen: via het nummerblok op het scherm).
  • Zet Developer mode op On, vul bij Host PC IP het IP-adres van je computer in en kies OK.
  • Zet de tv helemaal uit en weer aan (houd de aan/uit-knop ingedrukt tot hij herstart).
  • Zoek het IP-adres van de tv op: Instellingen → Algemeen → Netwerk → Netwerkstatus → IP-instellingen.

2. Tizen Studio en een Samsung-certificaat

  • Installeer Tizen Studio (de versie met IDE).
  • Installeer via Tools → Package Manager → Extension SDK de Samsung Certificate Extension en de TV Extensions (de nieuwste).
  • Verbind de tv: Tools → Device Manager → Remote Device Manager → +, vul het IP-adres van de tv in (poort 26101) en zet de schakelaar aan. De tv verschijnt in de lijst.
  • Open Tools → Certificate Manager → + en kies Samsung → TV. Geef het profiel een naam (bijvoorbeeld bingr), maak een nieuw auteurscertificaat met een wachtwoord dat je goed bewaart, log in met je Samsung-account en maak een nieuw distributeurscertificaat met privilege Public. De DUID van de verbonden tv staat er automatisch in; andere tv's kun je hier toevoegen.
  • Maak een back-up van de certificaatbestanden (bijvoorbeeld ~/SamsungCertificate/bingr/author.p12 en distributor.p12): met een ander auteurscertificaat installeert een update niet meer over de oude versie heen.

3. De app installeren

  • Met Tizen Studio: klik in de Device Manager met de rechtermuisknop op de tv, kies Install app en selecteer het .wgt-bestand.
  • Met de opdrachtregel (de tools staan in ~/tizen-studio/tools en ~/tizen-studio/tools/ide/bin): verbind met sdb connect <ip-van-je-tv>, bekijk de naam van de tv met sdb devices en installeer met tizen install -n Bingr-….wgt -t <naam-van-je-tv>.
  • Weigert de tv het bestand vanwege het certificaat, onderteken het dan eerst met je eigen profiel: tizen package -t wgt -s bingr -- Bingr-….wgt, en installeer het daarna opnieuw.
  • Bingr staat daarna bij Apps op de tv. Log in met de QR-code of via bingr.online/koppelen.

Developer Mode staat alleen open voor het IP-adres dat je hebt ingevuld en mag na de installatie aan blijven; zet je hem uit, dan blijft de app gewoon werken. Na een update van de tv-software moet je Developer Mode soms opnieuw aanzetten. Nieuwe tv, of is het distributeurscertificaat verlopen? Maak een nieuw distributeurscertificaat met het bestaande auteurscertificaat en voeg de DUID van de tv toe.

Samsung TV bijwerken

Installeer de nieuwe .wgt op dezelfde manier over de oude heen. Met hetzelfde auteurscertificaat blijven je login, profielen en instellingen bewaard. Met een ander certificaat weigert de tv de update; verwijder dan eerst de oude app en log opnieuw in (de tv telt dan als nieuw apparaat). Wat er nieuw is per build, lees je in de changelog.

Installing on Samsung TV

Installing the .wgt with Developer Mode, Tizen Studio and your own Samsung certificate.

Downloads are temporarily unavailable. The apps are coming soon. Until then, watch in your browser with your account at bingr.online/web. If you already installed Bingr, it keeps working.

Bingr on a Samsung TV

Bingr for Samsung TV (Tizen) works on Samsung smart TVs from 2018 and newer. You install the .wgt file from a computer using the TV's Developer Mode and your own Samsung certificate. Download the file with the Download for Samsung TV (.wgt) button at bingr.online.

1. Turn on Developer Mode on the TV

  • Make sure the TV and your computer are on the same network and look up your computer's IP address (macOS: System Settings → Network; Windows: ipconfig).
  • Open Apps on the TV and enter 1 2 3 4 5 with the remote (without number keys: via the on-screen number pad).
  • Set Developer mode to On, enter your computer's IP address under Host PC IP and choose OK.
  • Turn the TV off completely and on again (hold the power button until it restarts).
  • Look up the TV's IP address: Settings → General → Network → Network Status → IP Settings.

2. Tizen Studio and a Samsung certificate

  • Install Tizen Studio (the version with the IDE).
  • Via Tools → Package Manager → Extension SDK, install the Samsung Certificate Extension and the TV Extensions (the newest).
  • Connect the TV: Tools → Device Manager → Remote Device Manager → +, enter the TV's IP address (port 26101) and turn the switch on. The TV appears in the list.
  • Open Tools → Certificate Manager → + and choose Samsung → TV. Name the profile (for example bingr), create a new author certificate with a password you keep safe, sign in with your Samsung account and create a new distributor certificate with privilege Public. The DUID of the connected TV is filled in automatically; you can add other TVs here.
  • Back up the certificate files (for example ~/SamsungCertificate/bingr/author.p12 and distributor.p12): with a different author certificate, an update no longer installs over the old version.

3. Install the app

  • With Tizen Studio: in the Device Manager, right-click the TV, choose Install app and select the .wgt file.
  • From the command line (the tools are in ~/tizen-studio/tools and ~/tizen-studio/tools/ide/bin): connect with sdb connect <your-tv-ip>, look up the TV's name with sdb devices and install with tizen install -n Bingr-….wgt -t <your-tv-name>.
  • If the TV refuses the file because of the certificate, sign it with your own profile first: tizen package -t wgt -s bingr -- Bingr-….wgt, then install it again.
  • Bingr then appears under Apps on the TV. Sign in with the QR code or via bingr.online/koppelen.

Developer Mode is only open to the IP address you entered and may stay on after installing; if you turn it off, the app keeps working. After a TV software update you sometimes have to turn Developer Mode on again. New TV, or has the distributor certificate expired? Create a new distributor certificate with the existing author certificate and add the TV's DUID.

Updating on Samsung TV

Install the new .wgt the same way over the old one. With the same author certificate, your sign-in, profiles and settings are kept. With a different certificate the TV refuses the update; remove the old app first and sign in again (the TV then counts as a new device). See what's new in each build in the changelog.
